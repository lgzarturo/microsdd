# convenciones

- Español neutro en docs y specs.
- Conventional Commits; cambios incompatibles de API del instalador usan `feat!`.
- Scope de tarea en `spec/<slug>/spec.json`; no editar `.microharnéss/` salvo tareas que lo permitan.
- Aprobaciones humanas (`approve`/`seal`) requieren TTY y sin `CLAUDECODE`.
